Goal #1 — Reproducibility

Determinism Pillars

The control flow is already pure. These five mechanisms make a whole run reproducible despite stochastic leaves.

Content cache = the spine

A sha256(canonical request) cache on execute_with_fallback is the only replay path for the default subprocess backends. Write only when !timed_out && !retryable && exit==0.

Seeds are a footnote

Seed / temperature plumb only to HTTP & native providers. The cli-subprocess and Anthropic-cloud paths stay stochastic and rely on the cache.

Collapse before the manager

A pure judge() drops unverified workers and ranks survivors — turning gate.verified from a byte-cap signal into a real selector.

Canonical projection, not raw bytes

Parity & run-hash fold over a seq/ts/pid/heartbeat-stripped, role-sorted event projection — built in Phase 0, reusing the repo's own strip_seq.

Quantize the two comparators

Both partial_cmp-on-score sites (telemetry.rs:501 and :537) become total via i64 quantization + a stable index tiebreak.

Goal #3 — Cheap models, working together

Amplification Blocks

How weak models compound into strong answers — every one of these is a free function, shippable with no framework.

Gate-as-filter

The manager spends its limited budget only on cited, non-blocked evidence — a weak manager, far better synthesis.

Best-of-N

N cheap samples + a deterministic judge beat one expensive call; the cache dedupes identical sub-prompts.

Verification chain

A cheap generator + a pure structural verifier catches missing-section / uncited output and retries once.

Iterative refinement

Models refine until output stabilizes (Jaccard) instead of burning a fixed iteration budget.

De-game the gate

Citations checked against the real index — not the literal /Users/ — so best-of-N stops amplifying gaming.

Each phase ships on its own

The Roadmap

Value lands in Phases 0–3 with free functions and a cache wrapper. The framework (P4) is conditional; if no second consumer appears, it is correctly never built.

P0 · Foundation + parity harness

Canonicalizer + a MemCacheRepo test path, an injected Clock, two total comparators — zero behavior change.

P1 · Typed worker channel

WorkerOutput replaces the concat; the manager prompt is pinned byte-identical by a snapshot test.

P1.5 · Amplification (no framework)

Gate-filter + best-of-N + verify-retry as free functions — goal #3 met with no new crates.

P2 · Content cache + seeds

Zero-token replay on subprocess agents; reproducible HTTP/native. Default-off behind --cache.

P3 · converge fix + observability

Jaccard early-stop plus the missing JobRecord / event / summary plumbing converge lacks today.

P4 · Block IR Conditional

DAG-as-data + collapse ~150 lines of manager dispatch — only if a real second consumer appears.

P5 · Replay surface + symmetry

swarm replay (zero LLM calls), --json result envelopes for all verbs, converge + ledger over MCP.
